# 체험용 모의 파일

| 파일 | 무엇 | 어디에 쓰나 |
|---|---|---|
| `mock-lecture-dalnim.mp4` | 모의 강의 영상 2분 53초 · 그림책 장면 + AI 합성 음성(ElevenLabs) + 자막 — 『달님은 하나예요』 초등 저학년 수업 | 강의 연습 도우미 → 녹화 올리기 (시연용) |
| `mock-lecture-dalnim.m4a` | 위 영상의 음성만 2분 53초 (ElevenLabs `eleven_multilingual_v2`, 목소리 '제인 Jane'으로 만든 AI 합성 음성 · 한국어 + 베트남어 인사·낱말) | 강의 연습 도우미 → 녹화 올리기 |
| `manuscript-dalnim.txt` | 『달님은 하나예요』 한국어·베트남어 원고 (프로토타입 예시 원고) | 그림책 제작 도우미 → 원고 넣기 |
| `manuscript-tet.txt` | 『엄마 나라의 설날』 한국어·베트남어 원고 — **팀이 만든 체험용 가상 원고** | 그림책 제작 도우미 → 원고 넣기 |

모의 녹음에는 연습 포인트를 일부러 넣었다: 꾸오이 전설 설명이 길고 빠르며 군더더기 말('어', '그', '저기', '그러니까')이 많음, 질문하고 기다리지 않고 바로 답함('등불 행진은 왜 밤에 할까요?'), 책에 있는 '월병'을 다루지 않음. 잘한 점도 넣었다: 한국 추석 경험을 묻는 질문으로 시작해 책으로 연결, 실물 별 등불 보여 주기, 질문 뒤 충분히 기다리기, 마무리에서 한 문장 정리("베트남에도 추석이 있고, 아이들이 별 등불을 들고 동네를 돌아요.").
