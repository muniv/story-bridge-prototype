# 스토리브릿지 프로토타입

GIST 서울의밤 × 아시안허브 PBL (2026) 작동하는 프로토타입 · **작가의 이야기를 책으로, 책을 교실로**.

배포: https://muniv.github.io/story-bridge-prototype/ · https://story-bridge-rust.vercel.app (같은 화면) · 이전 버전: [v0.3](https://muniv.github.io/story-bridge-prototype/v0.3/)

## v0.6 (2026-10-25): 팀 서버

- `api/` Vercel 서버리스 함수가 OpenAI 키를 서버에만 두고 받아쓰기(`/api/transcribe`)·평가와 나누기·태그(`/api/chat`)·그림(`/api/image`)을 대신 호출한다. 키가 없는 사람도 입장 코드만 넣으면 실제 분석이 돌아간다.
- 환경 변수: `OPENAI_API_KEY`(필수), `DEMO_CODE`(입장 코드), `RATE_LIMIT`(10분당 요청 수, 기본 120), `LLM_MODEL`·`STT_MODEL`·`IMAGE_MODEL`(선택)
- 녹화는 브라우저에서 2분 단위 WAV로 나눠 4MB 아래로 보낸다(Vercel 본문 크기 제한). 개인 키를 넣으면 서버 대신 브라우저에서 OpenAI로 바로 보낸다.
- 첫 화면 리디자인(분할 히어로·실제 제품 화면·흐름·기능 소개), Phosphor 아이콘, 글 줄이기, 라이트 모드 고정

## 구성 (v0.6, 2026-10-25)

- **서비스 소개**: 작가의 이야기 → 그림책 제작 → 이중언어 그림책 → 강의 연습 → 교실 수업 → 아이들
- **1순위 · 강의 연습 도우미**: 모의 강의 녹화(파일 업로드 또는 브라우저 녹음) → 자가평가 → AI 분석 → 피드백 리포트
  - API 키가 있으면 **실제 분석**: whisper-1 받아쓰기(시간 표시) → 말 빠르기·군더더기 말·질문 뒤 기다림·인식 신뢰도 계산 → GPT가 교육과정 기준 6항목 평가, 잘한/고칠 순간, 문화 요소 체크, 다음 목표 작성 → 받아쓰기 전문 표시
  - 24MB가 넘거나 영상이면 브라우저에서 16kHz 모노 WAV 10분 조각으로 바꿔 보냄(30분 이하)
  - 평가 6항목: 학년 눈높이 · 한국어 발음 · 책 활용과 수업 흐름 · 문화 요소 전달 · 질문과 기다림 · 시간 배분
  - 수업 대상(학년군)·월 주제를 고르면 연계 성취기준을 보여 주고, 리포트에 책 속 문화 요소 체크를 표시
- **2순위 · 그림책 제작 도우미**: 완성된 글(한국어+모국어) → 그림 스타일·주인공 → 장면 그림 → 편집·조판 → **교육과정 태그**
  - 원고 파일(txt·md·docx) 올리기, **AI로 페이지 나누기**(원고 문장은 바꾸지 않음), 교육과정 태그는 원고에 실제로 있는 문장만 근거로 남김
  - 오른쪽 위 **API 설정**에 OpenAI API 키를 넣으면 그림 생성이 실제로 동작 (`gpt-image-1-mini` 기본)
  - 키는 브라우저 localStorage에만 저장되며, 요청은 브라우저에서 api.openai.com으로 직접 전송
- **공통 · 교육과정 기준**: 2022 개정 초등학교 교육과정(교육부 고시 제2022-33호) 기반 월별 주제 9개 × 저·중·고 학년군, 연계 성취기준, 책 매칭 5단계

체험용 모의 파일: [`samples/`](samples/) · 모의 강의 영상 `mock-lecture-dalnim.mp4`(그림책 장면 + 합성 음성 + 자막, 약 2분), 음성만 있는 `.m4a`, 원고 2편(1편은 가상 원고).

그림책 예시 그림: [`img/book/`](img/book/) · 『달님은 하나예요』 6장면과 표지(ChatGPT 이미지 생성, 주인공 시안 `img/char-1.jpg`와 수채화 스타일 샘플을 기준으로 일관되게). 키가 없어도 샘플 책에는 이 그림이 보인다.

대표님 피드백(10/16)에 따라 강의 연습을 1순위, 그림책 제작을 2순위로 두었다. 수업 기획(수업안 자동 생성)은 다른 학교 팀과 겹쳐 후순위.

정적 페이지(`index.html`)라 그대로 GitHub Pages로 배포된다.
