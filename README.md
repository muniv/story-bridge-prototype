# 스토리브릿지 프로토타입

GIST 서울의밤 × 아시안허브 PBL (2025) 클릭형 프로토타입.

- **1순위 · 강의 연습 도우미**: 모의 강의 녹화를 올리면 AI가 전달력·발음·내용을 평가 (현재는 예시 데이터)
- **2순위 · 그림책 제작 도우미**: 완성된 글(한국어+모국어)에 AI 그림과 자동 조판을 붙임
  - 오른쪽 위 **API 설정**에 OpenAI API 키를 넣으면 그림 생성이 실제로 동작 (`gpt-image-1-mini` 기본)
  - 키는 브라우저 localStorage에만 저장되며, 요청은 브라우저에서 api.openai.com으로 직접 전송

정적 페이지 한 장(`index.html`)이라 그대로 GitHub Pages로 배포됩니다.
