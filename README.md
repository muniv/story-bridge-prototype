# 스토리브릿지 프로토타입

GIST 서울의밤 × 아시안허브 PBL (2025) 클릭형 프로토타입. 강의 연습 도우미 하나에 집중합니다.

- **강의 녹화 평가**: 모의 강의 녹화를 올리면 AI가 전달력·발음·내용을 평가 (평가·전사는 예시 데이터)
  - 리포트에서 타임라인·전사 전문·내용 체크를 누르면 영상의 그 순간으로 이동. 실제 영상/음성 파일을 올리면 그 파일이 재생되고, 샘플은 슬라이드 모의 화면 + 음성 합성으로 대신 보여 줌
  - 2회차 점수 비교, 자가평가 vs AI 차이 인사이트, 분석 단계의 실시간 받아쓰기(시연용 건너뛰기 포함)
- **책과 맞춰 보기**: 강의에 쓰는 책 PDF를 올리면 강의에서 한 말을 책 장면과 대조해 읽은 장면·길어진 장면·빠진 장면을 표시 (대조 결과는 예시 데이터, 올린 PDF는 리포트에서 열어 볼 수 있음)
- **발음 연습**: 흐리게 들린 단어를 골라 들린 발음과 목표 발음을 비교하고, 모범 발음을 들은 뒤 따라 말하기
  - 따라 말하기는 브라우저 음성 인식(Web Speech API, `ko-KR`)으로 실제 동작. Chrome에서 마이크 권한이 필요하고, 지원하지 않는 브라우저에서는 연습 횟수만 기록
  - 어떤 단어가 흐렸는지 찾아내는 부분은 예시 데이터

정적 페이지 한 장(`index.html`)이라 그대로 GitHub Pages로 배포됩니다.
