# 스토리브릿지 프로토타입

GIST 서울의밤 × 아시안허브 PBL (2026) 작동하는 프로토타입 · **작가의 이야기를 책으로, 책을 교실로**.

배포: https://muniv.github.io/story-bridge-prototype/ · https://story-bridge-rust.vercel.app (같은 화면) · 이전 버전: [v0.3](https://muniv.github.io/story-bridge-prototype/v0.3/)

## v0.8 (2026-10-26): 근거 장면 바로 듣기 · 조판 글 배치 · 도구 화면 개편

- **근거 장면 바로 듣기**: 리포트에서 ▶를 누르면 화면 아래 플레이어가 그 구간만(앞뒤 1.5초) 재생하고 끝에서 멈춘다. 재생 중인 받아쓰기 문장을 강조. 점수 행·타임라인 잘한/고칠 순간·한 문장·문화 요소·발음 주의 구간이 같은 플레이어를 쓴다. 근거가 없는 항목은 버튼이 흐리게 보이고 눌리지 않음. 모의 영상·파일·브라우저 녹음(소리만) 모두
- **새 모의 강의 영상**: ElevenLabs 합성 음성(2:53) + 그림책 장면 슬라이드. 베트남어 인사·단어, 일부러 넣은 연습 포인트(질문 뒤 바로 답함, 전설 설명이 빠르고 군더더기, 월병을 다루지 않음)와 잘한 점(경험 질문 도입, 실물 등불, 한 문장 정리). 키 없이 보는 '예시 결과'도 이 영상을 실제로 분석한 결과라 근거 장면이 영상과 맞음
- **문화 요소 판정 보강**: AI가 빠뜨린 요소를 채우고(받아쓰기에 없으면 빠짐), 전함·부족은 근거 장면(t, 인용)을 받음
- **조판 글 배치**: 글 위치 4가지(그림 옆 · 글 먼저 · 그림 위 위쪽 · 그림 위 아래쪽) × 글자 크기 3단계, 모든 쪽에 적용, AI 배치로 되돌리기(전체·이 쪽만), 이 브라우저에 저장. AI 페이지 나누기가 펼침면마다 배치를 제안. 글이 넘치면 한 단계씩 줄이고 가장 작은 크기에서도 넘치면 '원고를 줄여 주세요'
- **도구 화면 개편**: 도구 머리 막대 + 연결된 단계 표시, 점수 원형 링·점수대 색(잘함 80+ · 보통 60~79 · 더 연습), 녹화 올리기 묶음 카드 + 따라오는 시작 카드(시작 조건 표시), 리포트 바로가기, 펼침면 카드·장면 썸네일·승인 막대, 조판 책상 배경·쪽 점. 노트북(1280px)·휴대폰(360px)에서 가로 스크롤 없음
- **강의 준비 흐름**: 메뉴를 우선순위가 아니라 수업 준비 순서로 — ① 책 준비 → ② 수업 설계(새 탭: 책·학년군·월 주제·전할 문화 요소·한 문장) → ③ 모의 강의 → ④ 코치 피드백. 네 단계 화면 위 흐름 띠(지금 단계·완료), 녹화 화면에 수업 설계 요약과 '바꾸기'. 그림책 태그·교육과정 기준의 다음 버튼은 수업 설계로. 1·2순위 표시 없음
- **나머지 화면도 같은 디자인**: 코치 확인(머리 막대·확인 전 개수, 목록과 항목마다 점수 링, 동의/조정 분절 버튼), 교육과정 기준(머리 막대, 학년군 아이콘 카드, 아이콘 제목), 기획 탭(원칙 아이콘, 업데이트 노트·로드맵 타임라인, 지표 아이콘, 질문 번호), API 설정 창(팀 서버·내 키 묶음)
- 검사: `story-bridge-prototype-qa/` smoke8(1280·360) · layout8(예시 책 두 권 × 배치 4가지 × 두 폭, 설날은 실제 AI 나누기) · analyze8(새 영상 실제 분석 조건 4개) + v0.7 검사 5개

## v0.7 (2026-10-26): 기획서 v3.1 반영

- **평가 기준표**: 6항목 × 저·중·고 학년군 기준표(초안 · 10/29 대표님 확인)를 교육과정 기준 탭에 보여 주고, 같은 표를 AI 평가 지시문(책 전용 예시를 뺀 일반형)과 리포트 점수 행에 함께 쓴다
- **근거 장면**: 점수마다 기준 문장과 근거 장면(시간 + 받아쓰기 문장, 누르면 그 장면으로). 받아쓰기에 없는 인용이거나 받아쓰기로 볼 수 없는 항목은 점수 대신 '확인 못 함'
- **아이들이 가져갈 한 문장**: 수업 정보에서 강사가 정하고(그림책에서 넘어오면 후보로 채움), 리포트가 전함·부족·빠짐을 근거 장면과 함께 판정. 비우면 AI 제안
- **회차 기록**: 분석마다 이 브라우저(localStorage `sb-v07`)에 저장 → 연습실 목록·점수 추이·지난 회차 비교·다음 목표 이어 받기. 예시 1·2회차가 처음부터 있고 '처음 상태로'로 실제 기록만 지움
- **코치 확인** (상단 탭): 보낸 리포트를 항목마다 동의·조정·메모로 확정. 확인한 회차는 코치 점수로 그래프·비교, AI–코치 차이를 항목별로 모아 '기준 보정 후보' 표시 (예시 회차 제외)
- **그림책 2단계 '문화 요소 확인'**: 원고에서 문화 요소를 실제로 뽑고(원고에 없는 인용 자동 제거) 작가가 확인한 목록이 그 책의 문화 요소가 됨 → 그림 지시문·교육과정 태그·강의 연습 체크 목록·평가·받아쓰기 힌트에 쓰임
- **기획 탭**: 원칙·업데이트 노트·로드맵·지표(실제 회차 기준)·비용·10/29 여쭐 것
- **11월 예정** 표시: 장면별 문화 표현 확인, 편집 담당자 검토, 인쇄용/리포트 PDF, 제작 기록, 코치 검토 시간 측정 (누르면 무엇이 언제 되는지 한 줄 설명)

## v0.6 (2026-10-25): 팀 서버

- `api/` Vercel 서버리스 함수가 OpenAI 키를 서버에만 두고 받아쓰기(`/api/transcribe`)·평가와 나누기·태그(`/api/chat`)·그림(`/api/image`)을 대신 호출한다. 키가 없는 사람도 입장 코드만 넣으면 실제 분석이 돌아간다.
- 환경 변수: `OPENAI_API_KEY`(필수), `DEMO_CODE`(입장 코드), `RATE_LIMIT`(10분당 요청 수, 기본 120), `LLM_MODEL`·`STT_MODEL`·`IMAGE_MODEL`(선택)
- 녹화는 브라우저에서 2분 단위 WAV로 나눠 4MB 아래로 보낸다(Vercel 본문 크기 제한). 개인 키를 넣으면 서버 대신 브라우저에서 OpenAI로 바로 보낸다.
- 첫 화면 리디자인(분할 히어로·실제 제품 화면·흐름·기능 소개), Phosphor 아이콘, 글 줄이기, 라이트 모드 고정

## 구성 (v0.6, 2026-10-25)

- **서비스 소개**: 작가의 이야기 → 그림책 제작 → 이중언어 그림책 → 강의 연습 → 교실 수업 → 아이들
- **1순위 · 강의 연습 도우미**: 모의 강의 녹화(파일 업로드 또는 브라우저 녹음) → 자가평가 → AI 분석 → 피드백 리포트
  - API 키가 있으면 **실제 분석**: whisper-1 받아쓰기(시간 표시) → 말 빠르기·군더더기 말·질문 뒤 기다림·인식 신뢰도 계산 → GPT가 교육과정 기준 6항목 평가, 잘한/고칠 순간, 문화 요소 체크, 다음 목표 작성 → 받아쓰기 전문 표시
  - 24MB가 넘거나 영상이면 브라우저에서 16kHz 모노 WAV 10분 조각으로 바꿔 보냄(30분 이하)
  - 평가 6항목: 학년 눈높이 · 한국어 발음 · 책 활용과 수업 흐름 · 문화 요소 전달 · 질문과 기다림 · 시간 배분
  - 수업 대상(학년군)·월 주제를 고르면 연계 성취기준을 보여 주고, 리포트에 책 속 문화 요소 체크를 표시
- **2순위 · 그림책 제작 도우미**: 완성된 글(한국어+모국어) → 그림 스타일·주인공 → 장면 그림 → 편집·조판 → **교육과정 태그**
  - 원고 파일(txt·md·docx) 올리기, **AI로 페이지 나누기**(원고 문장은 바꾸지 않음), 교육과정 태그는 원고에 실제로 있는 문장만 근거로 남김
  - 오른쪽 위 **API 설정**에 OpenAI API 키를 넣으면 그림 생성이 실제로 동작 (`gpt-image-1-mini` 기본)
  - 키는 브라우저 localStorage에만 저장되며, 요청은 브라우저에서 api.openai.com으로 직접 전송
- **공통 · 교육과정 기준**: 2022 개정 초등학교 교육과정(교육부 고시 제2022-33호) 기반 월별 주제 9개 × 저·중·고 학년군, 연계 성취기준, 책 매칭 5단계

체험용 모의 파일: [`samples/`](samples/) · 모의 강의 영상 `mock-lecture-dalnim.mp4`(그림책 장면 + 합성 음성 + 자막, 약 2분), 음성만 있는 `.m4a`, 원고 2편(1편은 가상 원고).

그림책 예시 그림: [`img/book/`](img/book/) · 『달님은 하나예요』 6장면과 표지(ChatGPT 이미지 생성, 주인공 시안 `img/char-1.jpg`와 수채화 스타일 샘플을 기준으로 일관되게). 키가 없어도 샘플 책에는 이 그림이 보인다.

대표님 피드백(10/16)에 따라 강의 연습을 1순위, 그림책 제작을 2순위로 두었다. 수업 기획(수업안 자동 생성)은 다른 학교 팀과 겹쳐 후순위.

정적 페이지(`index.html`)라 그대로 GitHub Pages로 배포된다.
